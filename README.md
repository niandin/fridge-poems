# fridge poems

A poetry reading and fridge magnet word-building site.

## Adding poets
Open `app.js` and add the poet's name to the `POET_NAMES` array.
Names must match exactly what PoetryDB uses — check available authors at:
https://poetrydb.org/author

## Deploy to Vercel
1. Push this folder to a GitHub repo
2. Go to vercel.com → New Project → import your repo
3. No build settings needed — just click Deploy
